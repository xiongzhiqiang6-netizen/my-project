# my-project

这是一个综合项目仓库，用于整理网页、Python 程序、学习笔记、AI 项目、爬虫和实用小工具。

## 项目简介

这个仓库用于长期存放和管理不同类型的练习项目、工具代码和学习资料，方便后续查找、维护和继续扩展。

## 仓库内容

- `README.md`：项目说明文档
- `.gitignore`：忽略本地临时文件、日志文件和构建产物
- `web/`：网页项目
- `python/`：Python 程序
- `notes/`：学习笔记
- `ai/`：AI 相关项目
- `crawler/`：爬虫项目
- `tools/`：实用小工具
- `docs/`：补充文档

## 使用方式

后续可以按项目类型把文件放入对应目录：

- 网页代码放到 `web/`
- Python 脚本放到 `python/`
- 学习资料放到 `notes/`
- AI 相关代码放到 `ai/`
- 爬虫脚本放到 `crawler/`
- 常用工具放到 `tools/`
